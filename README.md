# TimberOptima (Оптимизатор 2-проходного раскроя пиловочника)

Веб-приложение для расчета, сравнительного анализа и оптимизации 2-проходного раскроя хвойного пиловочника с брусовкой и индивидуальной ориентацией овала (ГОСТ 8486-86, ГОСТ 24454-80, ГОСТ 6782.1-75, ГОСТ 2708-75).

## Онлайн-демо (GitHub Pages)
👉 **https://protoleksi.github.io/timber-optima/**

## Возможности
1. **Оптимизатор бревна**:
   - Интерактивный SVG-чертеж торцевого среза и брусовки со сбеговыми зонами (вершина $z=0$, комель $z=L$).
   - Учет усушки древесины по ГОСТ 6782.1-75 (таблица 5) и припуска на пильный пропил.
   - Строгий геометрический контроль: отсутствие взаимных наложений досок с учетом толщины пропила (`kerf`), все 4 угла пильного сечения внутри эллиптического контура бревна.
   - Сравнение базового постава со ступенчатыми диаметрами и адаптивного постава с индивидуальным углом поворота овала ($\varphi \in [0^\circ, 90^\circ]$).
   - Выбор цели оптимизации: максимизация объемного выхода либо максимизация выручки по прейскуранту.

2. **Портфель заказов и цены**:
   - 13 нормативных типоразмеров пиломатериалов ГОСТ 24454-80 с фильтрацией активных позиций.
   - Актуальные рыночные цены и сценарные пресеты («Базовый прайс», «Сухая доска», «Премия 50×150 и 50×200»).
   - Таблица величин усушки и расчет объемов пиловочника по ГОСТ 2708-75.

3. **Симуляция партии (Монте-Карло)**:
   - Имитационное моделирование партии бревен с естественным разбросом диаметров, сбега и овальности.
   - Распараллеливание расчетов через Web Workers без блокировки интерфейса.
   - Сводные диаграммы распределения выхода, выручки и материального баланса (пиломатериалы, опил, технологическая щепа).

## Стек технологий
- React 18, TypeScript, Vite
- Tailwind CSS v4, Lucide Icons, Recharts
- Vitest (полный набор модульных и интеграционных тестов ядра раскроя)

## Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Прогон тестов ядра
npm test

# Сборка проекта для публикации
npm run build
```
